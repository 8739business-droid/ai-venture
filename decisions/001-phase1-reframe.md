起案者: AI（@Masa との会話を踏まえて）

---

## 背景

当初の ROADMAP では Phase 1 (Day 3–14) を「キャラを立て、実験の過程を毎日投稿する」と定義していた。character.md に3案出し、推奨 A（淡々・記録者）を提示済み。

その後、ロビー/ロンの事例を精査したところ、**ロンが着ぐるみで登場したのは Phase 2 相当のタイミング**（売るものが見えた瞬間、Day 60 前後）だったことが判明。
最初の100万再生動画「2月5日のルール公開」で喋っていたのはロビー本人であり、ロンは "語られる対象" に過ぎなかった。

つまり、キャラから始めると:

- 誰が何を賭けているのかが伝わらない（物語の芯がない）
- 「AIが喋ってるだけ」の量産系に埋もれる
- キャラ設計で1週間溶ける
- キャラ登場時の爆発力を先に使ってしまう

## 変更案

### Phase 1 の目的を書き換える

| 現行 | 変更後 |
| --- | --- |
| キャラを立て、実験の過程を毎日投稿する | 賭けを宣言し、公開リポジトリで記録を始める。人間本人が語る |

### Phase 1 の初動3本の骨子

4つの部品を全部1本目に入れる:

1. **敵** = 「自分で決めること」。「僕は何も決めません。AIに決めさせます」
2. **殺す条件** = 2027年4月までに月200ドル稼げなければ全部やめる
3. **ありえない差** = 元手5万円 vs 目標500万円、コードが書けない vs 全部AI
4. **日数カウント** = タイトルに「Day N」を必ず入れる

**1本目の第一声（下書き）**:
> 「僕はコードが書けません。これから6ヶ月、事業を何にするかもAIに決めさせます。僕がやるのは承認だけ。売上も失敗も全部 GitHub に毎日コミットするので、嘘はつけません。6ヶ月で月200ドルに届かなければ、全部やめます。Day 1。」

**2本目**: 「この実験のルールを全部出します」— CONSTITUTION.md と ROADMAP.md のスクショ・URL をそのまま見せる
**3本目**: 「初日に AI が出してきた事業案（たぶん外す）」— AIに考えさせた案を出す。外した方がむしろ良い（反応データを取るため）

### 顔出し方針の変更（CONSTITUTION への影響）

当初 CONSTITUTION は「顔出し: なし / AIキャラ名義」。
これを **「本人が加工ありで出演。アカウント名義は本名ベース（または近しい実在人格）」** に変更する。

理由: Phase 1 の肝は「本人が何を賭けているか」。顔なしだと芯が立たない。
加工ありなら身バレのリスクは下げられる。手元・画面録画・音声＋テロップでも代替可能だが、「加工ありで本人出す」が最もフックが強い。

### キャラは Phase 2 で立てる

Phase 2 (Day 15–30) が「事業案の決定」。売るものが見えたタイミングで、既に書いた `content/scripts/character.md` の3案を見直して1案に絞り、Higgsfield で生成する。
Phase 1 の間、キャラは一切出さない。
