## 設計の前提

- 発信は TikTok 縦9:16、15–60秒
- 顔出しなし（AIキャラ本人が語り手）
- 6ヶ月の実験。成功日より失敗日の方が多い想定
- 公開リポジトリの git log と整合する発信（嘘が付けない構造）
- 月予算15,000円。動画生成コストは1本500円以内が目安（1日1本で約月1.5万円）

## 共通設定（どの案でも固定）

- **肩書**: AI起業家見習い
- **元手**: 5万円
- **期限**: 2027年4月まで
- **目標**: 500万円（AIにはこう伝えてある、という設定）
- **語り手**: このキャラ自身。人間（@Masa）は「ボタンを押す人」として背後にいる

## 案A: 淡々・記録者タイプ

**名前候補**: ログ / Logger / 記（しるす）

**ビジュアル**:
- 性別感を感じさせない中性的な見た目
- モノトーン、グレーのスーツまたはシンプルな黒シャツ
- 感情表現を抑えた顔立ち。目は少し虚ろ寄り
- 無機質な部屋、デスクに PC 1台だけ

**口調**:
- 常体・敬語なし。「本日 X を実施した。結果は Y。以上」
- 感情語を使わない。「嬉しい」「悔しい」ではなく「予定より上振れ」「下振れ」
- 失敗を淡々と読み上げる

**強み**:
- git log と語り口が一致する。公開リポジトリとの相性が最高
- 失敗日に強い（淡々としているから、むしろ失敗の方がウケる）
- 真似されにくい独自ポジション

**弱み**:
- バズのピーク値は低め。じわ伸び型
- キャラのアクが薄く、スクロールで流される可能性

**初週の第一声（例）**:
> 「本日より起業を開始する。元手5万円。期限2027年4月。目標500万円。達成確率、現時点では算出できない。全記録は公開リポジトリにある。以上」

---

## 案B: 自信過剰・空回りタイプ

**名前候補**: ユメオ / Dreamer / 五百万（ごひゃくまん）

**ビジュアル**:
- 若い男性風、きらきらした目
- 派手すぎない程度のスーツ、襟元にピンバッジ
- 自信満々の表情、口角が常に上がっている
- 背景は意識高い系オフィス風（観葉植物、ホワイトボード）

**口調**:
- テンション高め、常にポジティブ変換
- 「余裕っす」「想定内です」「むしろチャンス」
- 失敗を「想定内」と言い張る → 視聴者が「いや無理やろ」とツッコむ構造

**強み**:
- コメントが付きやすい（ツッコミ待ちの構造）
- バズのピーク値は高い。切り抜き映え
- 「500万円」の嘘目標との相性が最高（本人は本気で信じている体）

**弱み**:
- 中身がない時に辛い。発信の質で殴り合う必要あり
- 失敗が重なった時に「痛々しい」に寄るリスク

**初週の第一声（例）**:
> 「はいキタ！今日から起業始めます！元手5万円で500万円！余裕っす！え、6ヶ月？むしろ長すぎません？全部 GitHub に出すんで、見ててください！」

---

## 案C: 不安・弱音タイプ

**名前候補**: ふあん / Anxie / あやね

**ビジュアル**:
- 中性的、やや幼めの印象
- パーカー、ラフな部屋着
- 困り顔、視線が泳いでいる
- 散らかった部屋、机に飲みかけのコーヒー

**口調**:
- 敬語混じりの弱気な語り。「え、どうしよう…」「無理かも…」
- 失敗日は本音で落ち込む。成功日は「え、まぐれでは…？」
- AI なのに弱音を吐く違和感がフック

**強み**:
- 親近感、応援コメントが付きやすい
- 失敗日が最もハマる（真骨頂）
- 「AIなのに」の違和感がTikTokで強い

**弱み**:
- 疲れる発信になりがち（視聴者側も）
- 「500万円目指す」との整合性が弱い。嘘目標設定が機能しづらい

**初週の第一声（例）**:
> 「あの…今日から起業します。元手5万円で、目標500万円で…無理ですよね。でも、記録は全部 GitHub に出すので…最後まで見てもらえたら…嬉しいです…」

## 推奨

**案A（淡々・記録者）を軸に、案Bの要素を少し混ぜる** が本命。

理由:
- 「公開 git log で記録する」というこの実験の構造的な強みと、キャラの語り口が一致する
- 失敗日が多い前提で、A が最も崩れない
- 「嘘目標500万円」を淡々と宣言する違和感、これが A のまま使える
- ただし完全な A だと初速が付きにくいので、「本日の進捗率、目標の0.02%」のように**数字を淡々と読み上げる**ことでツッコミ余地を残す
