# Reality セットアップ手順（Phase 1 用）

Phase 1 の「加工ありの本人出演」を Reality（iPhone 用 VTuber アプリ）で実現する。
Phase 2 でキャラが登場するタイミングでは、別のキャラに切り替える前提。Phase 1 では「シンプルで無個性なアバター」で OK。

## 1. インストールと初期設定（約10分）

1. App Store で「REALITY」を検索してインストール（開発元: GREE, Inc.）
2. アカウント作成（メールまたは Apple ID で可）
3. アバター作成画面で、できるだけ**無個性でシンプル**なプリセットを選ぶ
   - 髪型・服はデフォルト寄り
   - 「見た目で先に印象が決まる」を避けたい（主役は台本と記録）
   - Phase 2 で本番キャラに切り替えた時のコントラストを残すため
4. アバター名は本名寄りで（TikTok 名と合わせる前提）

## 2. 配信ではなく「収録」モードを使う

Reality は配信アプリだが、収録して TikTok に転載する運用にする。理由: 公開前に @Masa の確認が必要（CLAUDE.md のルール）。

- Reality 内の「配信」ではなく、**iPhone の画面収録機能**（コントロールセンターの「画面収録」ボタン）を使う
- アバター表示状態で Reality を開く
- 画面収録を開始してから話す
- 収録後、iPhone の「写真」アプリに動画が保存される

## 3. 音声の品質

- マイクは iPhone 内蔵でも最初は OK
- 静かな部屋で収録
- 口元を手で覆わない（Reality の口パク精度が落ちる）

## 4. 編集（CapCut 推奨）

- CapCut（無料アプリ）を App Store からインストール
- Reality の収録動画を読み込む
- テロップを入れる（音なしで見られる人向け）
- 冒頭 1 秒にフック用のテロップを強調で入れる
- 縦9:16、15〜60秒を目安に切り出す
- 書き出し → iPhone に保存

## 5. TikTok 投稿前のチェック

- @Masa が最終動画を再生して確認する
- 以下を目視:
  - 身バレ要素（部屋の背景・声・写り込み）
  - 発言の正確性（CONSTITUTION と矛盾していないか）
  - リポジトリ URL の表示
- OK なら TikTok に上げる。NG なら撮り直す（撮り直しは失敗としてログに書く）

## 6. 投稿時の設定

- 「AI生成コンテンツを含む」のトグルを ON
  - 顔は本人の動きだが、見た目がアバターなので宣言しておく方が安全
- Bio 欄に GitHub URL を貼る（可能なら）
